# Service Costing and Price-Floor Worksheet

> Internal planning aid, not a universal rate card or financial advice. Complete it using local costs and currency. Set a valid quote only after confirming scope and applicable taxes/fees.

## 1. Estimate true delivery cost

| Input | Your value | Notes |
|---|---:|---|
| Delivery labour hours |  | Include review and customer meetings |
| Preparation and follow-up hours |  | Do not hide admin time |
| Fully loaded labour cost per hour |  | Include a realistic share of employment/self-employment costs |
| Subcontractor cost |  | Include any specialist work |
| Tooling/hosting allocation |  | Per-engagement share |
| Travel and expenses |  | If applicable |
| Risk/contingency allowance |  | Explain why it is needed |
| Allocated overhead |  | Insurance, bookkeeping, training, sales, equipment, unpaid admin |

Calculate:

- Labour cost = (delivery hours + preparation/follow-up hours) × loaded labour cost per hour.
- Total cost base = labour + subcontractors + tooling/hosting + travel/expenses + risk allowance + allocated overhead.

## 2. Select a target gross margin

Gross margin is not the same as adding a markup to cost.

If the target gross margin is represented as a decimal from 0 to less than 1:

- Price floor before applicable taxes/fees = total cost base ÷ (1 − target gross margin).

Choose the target using market research, risk, scope, and business needs. If the result is above what customers value, revisit scope, delivery efficiency, or the offer; do not conceal an unprofitable service with unrealistic time estimates.

## 3. Add local transaction costs

Account for taxes, payment processing, currency conversion, and other chargeable costs as appropriate for the business and jurisdiction. Confirm with a local accountant or qualified adviser how each should be treated in a quote.

## 4. Quote guardrails

- [ ] The scope and acceptance criteria are written down.
- [ ] Included hours/limits and exclusions are explicit.
- [ ] A production change or additional investigation requires separate approval.
- [ ] Emergency response is not implied unless sold with a written response commitment.
- [ ] The quote says what evidence will be delivered—and what cannot be proven.
- [ ] No unqualified Luminous automation is represented as an included feature.
- [ ] The quote remains viable if preparation, review, and customer communication take the estimated time.

## 5. Review after delivery

Record actual hours, direct costs, rework, blocked inputs, and customer feedback. Compare to the estimate. Update the next quote based on observed work rather than treating an early promotional price as a permanent price list.
